Criteria voor Claude

Timing

Zo lang wacht GitHub op controle door je pc voordat hij een kandidaat toch mailt.

De rest volgt het volgende kwartier.

Zoekpagina's voor de pc thuis

Alleen pagina 1 wordt gelezen: zet de zoekpagina op "nieuwste eerst". Pararius en Huurwoningen hebben vaste code; bij andere sites leest Claude de advertentie (één aanroep per nieuwe advertentie).

Site toevoegen

Stukje van de link dat in elke advertentie staat. Open een advertentie en kijk naar het adres: bij site.nl/huren/amsterdam/123-straat is dat /huren/amsterdam/.

Alert-mails (GitHub)

Een stukje van het afzenderadres, bv. funda. Stel op die site een alert in naar je alert-Gmail; Claude leest de mail uit.

GitHub-koppeling

Kijken kan zonder, voor opslaan is een token nodig. Het token blijft alleen in deze browser.

  1. Open github.com → nieuw fine-grained token
  2. Repository access: Only select repositories → woning-monitor
  3. Permissions → Repository → Contents: Read and write
  4. Generate token en plak hem hieronder
